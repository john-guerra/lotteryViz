# front

React frontend for the lottery app, built with Vite.

## Scripts

- `yarn dev` — starts the Vite dev server (proxies API requests to the backend at `http://localhost:4001`).
- `yarn build` — builds the production bundle into `front/build`, which the Express backend serves.

For the full development workflow (starting the backend, running the whole test suite, database backups, etc.), see the repo-root [`CLAUDE.md`](../CLAUDE.md).
